# Android Dev Monitor v2.6.1

This patch refreshes the most frequently used workspaces and improves log and network inspection.

## Highlights

- Discovered devices and emulators now appear as responsive cards with clearer status and hardware details.
- Logs include one-click presets for device output, errors, warnings, crashes/ANRs, and bookmarks.
- Logs and File Explorer controls wrap cleanly at narrower window sizes.
- Data-grid selection, text alignment, file/folder labels, and dark scrollbars are more consistent.
- DNS parsing validates IPv4 and IPv6 addresses and reads every connectivity DNS section.

## Verification

- Release build completes with 0 warnings and 0 errors.
- All 69 automated tests pass.
- The self-contained Windows x64 package starts in demo mode and reports version 2.6.1.
