# Android Dev Monitor v2.8.1

A patch release for v2.8.0.

## Fixed

- **Closing the app no longer shows an error.** In v2.8.0, closing the window showed "Cannot set Visibility to Visible or call Show, ShowDialog, Close, or WindowInteropHelper.EnsureHandle while a Window is closing". The window now closes cleanly once the session is saved and any active screen recording has been pulled.

Everything else is unchanged from v2.8.0. See the [v2.8.0 release notes](https://github.com/marko69420/android-dev-monitor/releases/tag/v2.8.0) for the full list of changes in this series.

Previous release: [v2.8.0](https://github.com/marko69420/android-dev-monitor/releases/tag/v2.8.0)
